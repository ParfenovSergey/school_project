## Проверка интерфейса

В Chrome открыт результат release-сборки Flutter. Проверены бирюзовый главный экран с прозрачной иллюстрацией, декоративная кириллическая типографика, облачные переходы и три иллюстрированные карточки. В методическом разделе проверены светлый фон и читаемость длинных материалов. Визуально проверена главная страница. Через меню открыты работы групп и методический раздел, через «Подробнее» — универсальная страница первой группы. Прямая ссылка на группу сохранила работоспособность после обновления страницы.

Отдельно проверено размещение сборки под `/school-project/`: прямая ссылка `/school-project/#/groups/group-1` загрузила тексты и элементы управления; переход на главную сохранил базовый путь репозитория.

Добавлены проверки необязательного пути к иллюстрации и корректного отображения при отсутствующем файле изображения. Автоматические UI-тесты проверили все шесть типов страниц при ширинах 320, 768 и 1440 px, клавиатурный переход, мобильное меню, неизвестный адрес и группу, отсутствие продуктов и ссылок, добавление четвёртой группы только через JSON. Проверена компоновка длинного названия при масштабе текста 200% и восстановление как общего макета, так и вложенного раздела после исправления JSON и нажатия «Повторить».

Тесты используют независимые данные из `test/fixtures.dart`. Совместимость настоящих редактируемых JSON с моделями проверяется дополнительно, без привязки к демонстрационным названиям и числу групп.

## Границы проверки

- Windows 10 и Edge в этой Linux-среде не запускались; команды и настройка приведены в README.
- Workflow подготовлен и проверен локально, но не запускался в пользовательском репозитории. Для публикации требуется создать репозиторий и включить GitHub Pages с источником GitHub Actions.
- Примеры URL ведут на example.com. Реальные внешние информационные продукты не предоставлены.
- Flutter при сборке сообщает о ссылках SDK на шрифт CupertinoIcons. Приложение использует MaterialIcons; их отображение проверено в браузере, сборка завершается успешно.

Сборочные каталоги и зависимости не включены в исходный ZIP. Для воспроизведения используйте команды из README; настройки и все необходимые исходные данные находятся в проекте.

## Ресурсы оформления

Включены четыре локальные WebP-иллюстрации, шрифты Amatic SC и Nunito с лицензиями OFL. Наличие кириллических символов проверено по таблицам символов шрифтов. Главная иллюстрация сохраняет альфа-канал. Все пути `imageAsset` в JSON указывают на существующие файлы. Точные промты и источники перечислены в `ASSETS.md`.
